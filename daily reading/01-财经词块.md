# 财经词块表

> 用法：只记搭配，不记孤词。每天挑 8 个，配 Anki 复习。
> 优先级：★★★ = 几乎每篇财经新闻都会出现，先背这些。

---

## 一、货币政策与宏观 ★★★

| 词块 | 释义 | 备注 |
|---|---|---|
| raise / cut interest rates | 加息 / 降息 | 也可说 hike / cut rates |
| a rate hike / a rate cut | 一次加息 / 一次降息 | 名词形式，新闻标题常用 |
| monetary tightening / easing | 货币紧缩 / 货币宽松 | |
| quantitative easing (QE) | 量化宽松 | |
| the central bank holds rates steady | 央行维持利率不变 | steady 是新闻高频词 |
| a hawkish pause | 鹰派式暂停 | 暂停加息但态度仍强硬 |
| inflation cools down / heats up | 通胀降温 / 升温 | 也常说 inflation runs hot |
| consumer price index (CPI) | 消费者物价指数 | |
| cost-of-living crisis | 生活成本危机 | 社会版高频 |
| gross domestic product (GDP) | 国内生产总值 | |
| a recession / a downturn | 衰退 / 下行 | |
| a soft landing | 软着陆 | |
